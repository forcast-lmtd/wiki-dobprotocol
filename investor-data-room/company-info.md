## Company Description

{% hint style="info" %}
Dobprotocol connects real projects with global investors through simple, transparent, and compliant WEB3 infrastructure. A complete ecosystem of solutions for Real World Asset (RWA) tokenization.

**Model:**\
Validates project performance on-chain and tokenizes future revenue, creating transparent and investable financial products.

**Result:**\
Stable yields for investors. Faster and more reliable funding for Project Owners.

***

**Use cases:**

* SaaS platforms with monthly subscriptions
* Farms validating grain production
* Factories delivering products
* Mining fleets: GPUs and AI clusters
* Solar and renewable energy
* EV charging networks
* Industrial robots
* Data and IoT infrastructure

***

**Any Productive System can be addressed by DOB Protocol**

Any system generating reliable, measurable data qualifies. SaaS with subscriptions. Farm validating production. Factory delivering products. Performance becomes visible and verifiable. Any Productive System with measurable data can be tokenized.
{% endhint %}

## Competitor Analysis

| Competitor        | Description                                                                                                                    | DOB Differentiation                                                                                                  |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| **Centrifuge**    | RWA platform that tokenizes invoices, real estate, and receivables into NFTs, used as collateral for DeFi lending pools.       | - Centrifuge uses credit/payment history. DOB uses live performance data verified from projects.                     |
| **Securitize**    | End-to-end tokenization and compliance platform for securities, enabling issuance, investor onboarding, and secondary trading. | - Securitize tokenizes asset/fund ownership. DOB tokenizes future revenue with performance validation.               |
| **Ondo Finance**  | Issues tokenized fixed-income products like U.S. Treasuries and bond ETFs for institutional investors.                         | - Ondo uses yield from existing financial products (bonds). DOB uses future infrastructure revenue.                  |
| **Maple Finance** | Decentralized institutional lending protocol offering undercollateralized loans to verified borrowers.                         | - Maple uses creditworthiness and reputation. DOB uses on-chain verified project performance.                        |
| **Pendle**        | Protocol for splitting and trading principal and yield components of tokenized assets.                                         | - Pendle is product agnostic. DOB originates yield from verified real infrastructure. Potential integration partner. |
